# Sai Veer — Portfolio Website
Responsive portfolio using HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser or use VS Code Live Server.

## Before publishing
- Replace `YOUR_EMAIL@example.com` with your actual email, or remove the email link.
- Confirm education, projects, and social links.
- Remove any project you do not want to display.

## Publish with GitHub Pages
1. Create a public GitHub repository named `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select `main` and `/(root)`, then Save.
6. Wait for deployment. URL format: `https://YOUR-USERNAME.github.io/portfolio/`.
